て形の変化規則

動詞（三類・二類・一類）＋ 形容詞・名詞 完全對照 ｜ 例句 ＋ 發音

三類

只有 する 系列與 来る。名詞＋する 的複合動詞全部同理，一律 ～して。

二類（る → て）

去掉字尾「る」加「て」。特徵：る 前面是 い段 或 え段（たべる・みる・おきる）。

一類（字尾依規則變化）

依最後一個假名分四組。N5 最核心，務必練到反射動作。
く → いて
書く→書いて
ぐ → いで
泳ぐ→泳いで
す → して
話す→話して
む・ぶ・ぬ → んで
飲む→飲んで
う・つ・る → って
買う→買って

⚠️ 特例・陷阱

① 行く 完全不規則　② 下列動詞外型像二類，其實是一類 ― N5 最常錯的地方。

形容詞のて形

い形容詞：去い＋くて（高い→高くて）。な形容詞：語幹＋で（静か→静かで）。
兩者的て形都用來 ①並列「又…又…」　②原因「因為…所以…」。
い形容詞 → ～くて
安い→安くて
いい／よい → よくて
特例，非「いくて」
ない → なくて
ない 本身是い形容詞
な形容詞 → ～で
便利→便利で
否定 → ～くなくて／～じゃなくて
高くなくて・静かじゃなくて

名詞のて形（名詞＋で）

名詞後面直接加 で（学生→学生で）。這個 で 來自斷定助動詞 だ 的て形， 所以和な形容詞完全同型。用法 ①並列說明「是A，而且…」　②原因「因為A所以…」。
名詞 → ～で
学生→学生で
な形容詞 → ～で
同型，一起記
否定 → ～じゃなくて
正式：ではなくて
